# Security policy

## Scope

This policy covers the code and maintainer workflows in this repository. The
public demo is illustrative and must not be used to submit confidential
material or credentials.

## Reporting a vulnerability

Please do not open a public issue for a security-sensitive report. Use the
repository's GitHub **Report a vulnerability** workflow when available, or
contact the maintainer through the email listed on the GitHub profile.

Never include API keys, private source images, personal data, or unpublished
heritage material in a report.

## Data and credentials

`.env` is ignored and `.env.example` contains placeholders only. The upstream
image manifest is metadata; the repository does not redistribute the image
corpus. Verify licensing and access rights before processing any source data.
